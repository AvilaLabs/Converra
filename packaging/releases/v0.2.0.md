## Engineering decision workspace

Converra 0.2.0 extends the existing egui workbench and the shared Rust engine:

- Named study variants, structured revisions, saved workspaces and retained
  historical evidence with exact input and dataset dependencies.
- Diagnoses, decision comparisons and explicit follow-up experiments that retain
  declared requirements and limits.
- A local stdio MCP server for AI agents: typed tools, cancellable background
  jobs, persistent studies, full-record resources and portable review exports.
- Verified exact-input reuse within a live engine session. Imported and reopened
  evidence stays outside the execution cache.
- Measured-conductor startup study, applicability checks, work estimates,
  multiple material dependencies and portable offline-verifiable review packages.
- Browser worker reuse, cancellation, responsive study controls and preserved
  page navigation. The GUI remains the Rust/egui application.

### Downloads

Windows x64 and Linux x64 archives contain the GUI, `optcoil` CLI and
`optcoil-mcp` server. Both macOS architectures have an app ZIP and a separate
CLI/MCP tar archive. All six archives include setup guides, example inputs,
license and dataset attribution. `SHA256SUMS` covers every archive.

### Compatibility and verification

Run records advance to v26, search checker identity to v23 and acceptance checker
identity to v19. Failed candidates with unavailable pre-screen quantities retain
JSON `null`; evaluated candidates still require finite quantities. Numerical
kernels and engineering gates are unchanged. Older records remain historical
evidence; recalculation uses the current engine identity.

The release workflow requires successful CI for the exact tagged commit and
builds all four supported platforms. The source workspace has 506 tests, and
the browser workflow was exercised through an isolated Chromium instance.

Converra preserves `PASS`, `FAIL`, `INCONCLUSIVE` and `NOT_EVALUATED`. Screening
and artifact verification do not establish engineering acceptance or independent
physics accuracy. External engineer validation remains open. Example prices are
illustrative, and supported material domains remain explicit.

Signing is optional and depends on configured release secrets. macOS headless
archives remain unsigned; unsigned app builds may trigger operating-system
security prompts. See [packaging details](https://github.com/AvilaLabs/Converra/blob/v0.2.0/packaging/README.md).
