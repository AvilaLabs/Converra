## Optional Avila Labs sign-in, spreadsheet import and draft recovery

Converra 0.3.0 adds an optional Avila Labs sign-in to the egui workbench, on the
desktop and in the browser, and ships the study work added since v0.2.0:

- Optional sign-in: a **Sign in** button and first-visit prompt in the browser;
  on the desktop, a device sign-in approved in your browser. A tool launcher
  links the other Avila Labs tools, and the app has a new icon. Nothing from
  your work is sent, and every feature works without an account.
- Spreadsheet import for bounded CSV, TSV and XLSX measurement tables with a
  source preview, explicit column/unit mapping and portable dataset bundles.
- Decision, reason and first next action presented together, with independent
  recomputation agreement labelled separately from the engineering outcome.
- Draft recovery for studies, exact inputs, completed evidence and import forms,
  with atomic desktop writes and browser transactions.
- Browser margin sweeps run in the calculation worker and can be cancelled.
- Ranked study diagnoses and bounded scenario reruns with retained replay
  evidence, workspace v2 with v1 import, MCP resources and a `study-robustness`
  CLI command.

### Downloads

Windows x64 and Linux x64 archives contain the GUI, `optcoil` CLI and
`optcoil-mcp` server. Both macOS architectures have an app ZIP and a separate
CLI/MCP tar archive. All six archives include setup guides, example inputs,
license and dataset attribution. `SHA256SUMS` covers every archive.

### Compatibility and verification

Numerical kernels and engineering gates are unchanged. Converra preserves
`PASS`, `FAIL`, `INCONCLUSIVE` and `NOT_EVALUATED`. Screening and artifact
verification do not establish engineering acceptance or independent physics
accuracy. External engineer validation remains open. Example prices are
illustrative, and supported material domains remain explicit.

Signing is optional and depends on configured release secrets. macOS headless
archives remain unsigned; unsigned app builds may trigger operating-system
security prompts. See [packaging details](https://github.com/AvilaLabs/Converra/blob/v0.3.0/packaging/README.md).
